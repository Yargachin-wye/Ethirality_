# 01. Ядро игры

## Фантазия
Игрок — «комок мяса» (`LumpMeat`) с челюстью и гарпуном, который поднимается вверх по
бесконечной вертикальной шахте из слоёв, пожирая живое и уклоняясь от неживого.
Гравитация тянет вниз; единственные способы двигаться — рывок и подтягивание гарпуном.

## Основной цикл (один слой ≈ 100 ед. высоты)

```
войти в слой снизу (безопасная зона 6 ед.)
  → оценить угрозы (стрелки, лазеры) и еду
  → подниматься: рывок / гарпун-подтягивание, зависая (freeze) для прицеливания
  → убивать и ЕСТЬ (рывок добивает → +HP), избегать контактного урона
  → подобрать LevelUp (если есть) → выбрать: +1 HP | конкретное улучшение | случайное
  → верх слоя = вход в следующий (сложность d растёт)
смерть (HP ≤ 0) → сброс сохранения → лобби
```

Игра про **управление двумя ресурсами** — HP и кулдаунами — при постоянном давлении
гравитации. Еда и награды восполняют HP; угрозы и выход за границы (`DeadZone`) его снимают.

## Глаголы игрока (ввод → действие)

| Ввод (`Inputer`) | Событие | Действие (`LumpMeatMovable` / `Shooter`) |
|---|---|---|
| Тап короче `tapDelay` | `OnInputShot(worldPoint)` | Выстрел гарпуном в точку (если `_timer ≤ 0`), задержка `shootDelay` |
| Удержание дольше `tapDelay` | `OnInputFreeze(true)` | **Freeze**: `gravityScale = 0`, скорость гасится `×(1 − decelerationRate)` за фикс. шаг, челюсть открывается при отклонении джойстика ≥ 0.9 |
| Джойстик при удержании | `OnInputLook(dir)` | Поворот к `−dir` со скоростью `rotationSpeed` |
| Отпускание с отклонением > 0.9 | `OnInputDash` | **Dash**: импульс `powerDash` вдоль взгляда, окно `dashTime` с уроном `dashDmg` по касанию, кулдаун `dashDelay` |
| Отпускание | `OnInputFreeze(false)` | Гравитация возвращается |

Следствия:
- Freeze бесплатен и неограничен → «зависание» — основной режим; гравитация давит только
  в момент перехода между действиями.
- Гарпон одновременно оружие и средство передвижения (см. `03`, «Гарпун»): попав в цель,
  тянет игрока к цели импульсом 50 и цель к игроку импульсом 20.

## Ресурсы

| Ресурс | Диапазон | Источники (+) | Стоки (−) | Где хранится |
|---|---|---|---|---|
| HP | 0…`maxHp` (7), старт 4 | еда рывком (+`hpCure`), выбор «+1 HP» на LevelUp | снаряды, контактные угрозы, `DeadZone` (1/с вне границ), `Poison` | `Stats` ↔ `SaveSystem.saveData.hp` (персистентно между сценами) |
| Кулдаун рывка | `dashDelay` с | время | каждый Dash/Push | `LumpMeatMovable` |
| Кулдаун гарпуна | `shootDelay` с | время | каждый выстрел | `Shooter` |
| Улучшения | список `playerUpgradeResIds` | LevelUp | `Improvement.Remove()` (щит с `isDestroyOnTrigger`) | `SaveSystem` |

## Условия конца
- **Поражение**: `Stats.Damage` → HP ≤ 0 у игрока → `GameOverEvent` → через 1 с `ResetGameData()` (HP = 4,
  улучшения очищены, `currentDifficulty = 0`) → лобби.
- **Победа/переход** (только ручные сцены): съесть `GameOverKey` → `currentDifficulty++` → экран выбора.
- **OpenWorld**: конца нет; после слоя `layerCount − 1` (29) включается «бесконечный» множитель угрозы.

## Что игра НЕ делает (важно для модели)
- Нет опыта/валюты: единственная прогрессия внутри забега — улучшения с LevelUp и HP.
- Нет урона по времени/голода: без угроз игрок бессмертен.
- Большинство врагов не агрятся: стрелки стоят, лазеры вращаются/плывут, пчёлы блуждают. Исключения: Chaser и Leaper преследуют, Charger бросается после телеграфа, Mine взрывается по таймеру, Runner убегает (см. `02`).
